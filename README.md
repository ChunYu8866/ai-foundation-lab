# 知序 AI · AI Foundation Lab

繁體中文 AI 基礎學習 App，依使用者提供的兩份 iPAS AI 初級 YouTube 播放清單編排。從 AI 概念、資料思維、機器學習到生成式 AI 與導入規劃，將影片主題串成可以練習、複習與記錄的學習路徑。

## 使用 App

[開啟知序 AI](https://chunyu8866.github.io/ai-foundation-lab/)（公開使用，免登入）

- **6 大模組、12 個單元**：原創導讀、學習目標、生活例子與一句重點。
- **17 部來源影片**：完整保留兩份清單的標題、順序、時長和 YouTube 連結；主題單元映射其中 16 部教學影片，考試分享保留於影片庫。
- **351 題原創詳解練習**：依官方 115.06 版 16 個初級評鑑細項增編 240 題，另完整保留並升級原 36 題；再依初級教材考點新增 75 題。每題附解題思路、四選項辨析、易錯陷阱、記憶線索、延伸觀念與一手來源。
- **16 份考點提要**：考前必背（依初級教材整理）、重點拆解、易混淆概念比較、自我檢查與涵蓋進度。
- **詳解閱讀與自訂練習**：依科目、細項、難度、熟悉度與關鍵詞篩選；每輪 10／20／50／100 題或全部。小測驗點選選項後立即判定正誤與顯示解析，不必送出；自訂模擬則於交卷後檢討。
- **錯題與不熟追蹤**：答對但靠猜也能標記；連續兩次答對且未標記才列為穩定答對。此指標僅用於學習，非正式通過預測。
- **24 張知識卡片**：中英術語搜尋、已熟悉標記。
- **個人學習紀錄**：完成進度、連續學習、單課筆記、題目標記與作答次數，支援 JSON 匯出與還原；進行中的練習另在裝置暫存，重新整理後可續做。
- **響應式 PWA**：桌機與手機皆可使用；首次成功載入並完成快取後，導讀與練習可離線使用，YouTube 影片仍需網路。

## 本機執行

需要 Node.js 20 以上，無第三方執行依賴，無須 API key。

```sh
npm run dev
```

開啟 `http://127.0.0.1:4173`。可用 `PORT=8080 npm run dev` 變更埠號。

```sh
npm run check
npm run build
```

`check` 執行 JavaScript 語法檢查及 Node 原生測試；`build` 將可直接部署的靜態檔案輸出至 `dist/`。可部署到任何支援 HTTPS 的靜態主機；所有資源使用相對路徑，也適用於 GitHub Pages 子目錄。正式網站由 GitHub Pages 從公開儲存庫的 `main` 分支根目錄發布。根目錄的 `.nojekyll` 停用 Jekyll 處理，保留原生 ES modules 與靜態資源路徑。更新 `main` 後，GitHub 會自動重新部署，無須 API key 或額外套件。

## 公開部署與 RWD

正式網址：<https://chunyu8866.github.io/ai-foundation-lab/>

GitHub 設定為 **Settings → Pages → Deploy from a branch → main → /(root)**。靜態入口已在根目錄，無須上傳 `dist/`；`npm run build` 仍可供其他靜態主機使用。所有路徑相對於目前專案，支援 GitHub Pages 的 `/ai-foundation-lab/` 子路徑。

介面依手機、平板與桌面寬度重排，包含900px側欄切換、可換行篩選列、課程卡片與雙欄導讀、44px觸控目標、長文字與筆記溢出保護。使用者無需登入；學習紀錄各自保存在自己的瀏覽器中。

如果原先在另一個網址使用 App，可先於舊網址「我的筆記」匯出備份，再在此公開網址匯入，接續個人進度。

## 證照備考範圍

以 [iPAS 官方 115.06 評鑑內容範圍參考](https://www.ipas.org.tw/api/proxy/uploads/certification_attachment/8039a24c849c4fb4a6dd7f942576d4f8/AI應用規劃師能力鑑定_評鑑內容範圍參考_11506_20260602161501.pdf) 的初級 16 細項作為編排索引，每項增加 15 題（基礎 5／應用 6／進階 4），題目難度為本 App 的學習分級。內容包括治理與風險、資料品質與隱私、學習類型、模型與混淆矩陣、鑑別與生成整合、No/Low Code、生成工具、提示、RAG、Agent、POC、KPI 與成本效益。

官方參考範圍並非封閉題單；這些原創題目不是官方題庫、歷屆試題、命中率或通過保證。自訂模擬題數與時間由學習者設定，非正式試卷。技術與治理內容引用的一手文件可於每題及每個考點查看，查核日為 2026-10-31。避免把精熟度或練習成績直接解讀為實際考試結果。

### 初級教材考點

另依使用者提供的 iPAS 初級教材（各考點講義、題庫解說、樣題比較、模擬題與考題探討）歸納考試常見重點，每個考點新增 4–6 題，題號以 `mt-` 開頭，可在題庫以「題組 → 初級教材考點」篩選，考點頁另列「考前必背」。中級教材未納入。題目、選項與解析皆為原創改寫，不轉載教材原題；教材註明部分內容由 AI 產製，與一手文件不一致處（例如縮寫定義、法規數字）以一手文件為準。

小測驗作答只更新既有選項與下方解析，不重建整個 App 或移動捲動位置；確認後鎖定本題，避免連點重複計分。進行中的模擬倒數在離開頁面或重新整理時仍會繼續，時間到會交卷；未作答題會標記為待複習。

## 個人資料與限制

學習資料保存在目前瀏覽器的 `localStorage`，沒有帳號同步、後端資料庫或外部 AI API。清除瀏覽器資料會遺失本機紀錄，切換網域也不會自動同步進度，請先在「我的筆記」匯出 JSON 備份，再到新環境匯入。匯入會在確認後覆蓋目前紀錄。

首次離線開啟無法建立快取。影片、YouTube 外連與技術參考文件需要網路；離線能力需瀏覽器支援 Service Worker，通常須 HTTPS 或 localhost。這是可安裝的網頁 App，並非 App Store／Google Play 原生應用程式。
